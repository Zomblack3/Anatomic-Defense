Anatomic Defense is a game inspired on the retro game "Asteroids" maded on C++ with the library "Raylib".

The game is setted on an hospital where a pacient is very sick with an extrange virus, the doctors decides to use their new tool, a micro-ship that it can be controled from outside, your job is use this ship to fight against the virus and try to heal the pacient.

Game project for the Higher Technical Degree in Video Game Development from Image Campus.
